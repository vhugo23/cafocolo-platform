# Cafocolo Platform

Cafocolo Operations Platform is a full-stack web application for managing customer leads, projects, payments, media documentation, and portfolio publishing for a construction and custom furniture service business.

## Planned Stack

- Frontend: Next.js + TypeScript
- Backend: Java Spring Boot
- Database: PostgreSQL
- Storage: Cloudinary or S3
- Deployment: Vercel + backend cloud host
